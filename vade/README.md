# VADE Cyber Club — сторінка-візитка кіберклубу

Сторінка «все в одному посиланні» для біо Instagram/TikTok: бронювання, соцмережі, ціни, графік, карта, аналітика.
Чотири мови: польська (основна), англійська, українська й російська.
Працює як звичайні статичні файли: сервер, база даних і збірка не потрібні.

## Файли

| Файл | Що це |
|---|---|
| `config.js` | **Увесь контент, переклади та ID трекерів — редагувати тут** |
| `index.html` | Сторінка. Міняти лише теги в `<head>` (назва, опис, домен) |
| `app.js`, `styles.css` | Логіка та стилі, чіпати не потрібно |
| `manifest.json`, `sw.js` | PWA: встановлення на телефон і робота без інтернету |
| `_headers` | HTTP-заголовки для Cloudflare Pages |
| `../functions/api/status.js` | Функція Cloudflare: вільні ПК з SENET (див. нижче) |
| `assets/` | Логотип, іконки сайту, `og-image.png` — картинка для прев'ю посилань (1200×630) |

## Що вже заповнено і що лишилось

1. **Домен** — у `index.html` в `<head>` замінити `https://vade.example/` на свій домен (4 місця: `canonical`, `og:url`, `og:image`, `twitter:image`). Можна вписати його й у `site.url` у `config.js`; поки там порожньо, береться адреса відкритої сторінки.
2. **Онлайн-бронювання** — поки його немає, головна кнопка дзвонить у клуб. Коли з'явиться система бронювання, вставити посилання в `booking.url` і змінити `booking.subtitle`.
3. **Ціни** — у `zones` вписати реальні ціни й характеристики. Зона без ціни не показується, а поки цін немає зовсім, секція «Зони та ціни» прихована.
4. **Фото** — покласти в `assets/photos/` і вписати шляхи в `gallery`, напр. `src: "assets/photos/hall.jpg"`. Поки фото немає, показуються фірмові заглушки.
5. **Інші посилання** — Discord, TikTok, меню бару, турніри: вписати `url`, коли з'являться.

Порожнє посилання (`url: ""`) просто ховає кнопку чи іконку, тож «битих» кнопок на сторінці не буде.

## Мови

- Кожен текст у `config.js` — об'єкт з перекладами: `{ pl: "…", en: "…", uk: "…", ru: "…" }`. Звичайний рядок (напр. `"VADE"`) показується однаково всіма мовами. Якщо якоїсь мови в об'єкті бракує, показується польський варіант.
- Підписи інтерфейсу (статус «Otwarte/Zamknięte», дні тижня, банер cookies, вікно «Поділитися» тощо) — у розділі `ui` в кінці `config.js`.
- У будь-якому тексті можна писати `{phone}`, `{address}` або `{name}` — підставиться з `contacts` і `site`.
- Як обирається мова: `?lang=en` у посиланні → мова, яку відвідувач уже обрав перемикачем (запам'ятовується в браузері) → мова браузера → польська.
- Посилання з `?lang=` зручні для QR-кодів і реклами для туристів: `https://ваш-домен/?lang=en`, `?lang=uk`, `?lang=ru`.
- `uk` — код української мови. На кнопці показується `UA`, а `?lang=ua` теж працює.
- Пошукові роботи завжди бачать польську версію, щоб Google індексував сторінку польською.
- Мовами керує `languages` на початку `config.js`. Щоб прибрати мову, видаліть її рядок зі списку.

## Аналітика

Вписати ID у `tracking` в `config.js`. Сервіс без ID не підключається.

| Сервіс | Де взяти ID | Поле |
|---|---|---|
| Google Analytics 4 | analytics.google.com → Адміністратор → Потоки даних → *Measurement ID* (`G-…`) | `ga4` |
| Google Tag Manager | tagmanager.google.com → ID контейнера (`GTM-…`) | `gtm` |
| Meta Pixel (Instagram/Facebook) | business.facebook.com → Events Manager → *Pixel ID* | `metaPixel` |
| TikTok Pixel | ads.tiktok.com → Інструменти → Події → Веб-події → *Pixel ID* | `tiktokPixel` |
| Microsoft Clarity (теплові карти, записи сесій) | clarity.microsoft.com → Settings → *Project ID* | `clarity` |

Використовуйте **або** `ga4`, **або** `gtm` з тегом GA4 всередині, але не обидва одразу, інакше відвідування порахуються двічі.

### Які події відправляються

| Дія відвідувача | GA4 / GTM | Meta | TikTok |
|---|---|---|---|
| «Забронювати ПК» | `booking_click` | `Schedule` | `ClickButton` |
| Дзвінок | `phone_click` | `Contact` | `Contact` |
| Соцмережі, Telegram, Discord | `social_click` | `social_click` | `ClickButton` |
| Інші кнопки (меню, турніри) | `link_click` | `link_click` | `ClickButton` |
| «Маршрут» / «Показати на карті» | `route_click` / `map_open` | `FindLocation` | `ClickButton` / — |
| Вікно «Поділитися», вибір мережі | `share_open`, `share` | так само | — |
| Галерея, копіювання адреси, QR | `gallery_interact`, `copy_address`, `qr_download` | так само | — |
| Перемикання мови | `language_switch` | `language_switch` | — |
| Кнопка трансляції | `live_click` | `live_click` | `ClickButton` |

Параметри подій: `link_id`, `link_text`, `link_url`, `site_language` (мова, якою відвідувач дивився сторінку). `link_text` завжди польською, щоб одна кнопка не розпадалась у звітах на чотири назви. У GTM ті самі події приходять з префіксом `vade_` (напр. `vade_booking_click`).

**Порада:** у GA4 позначте `booking_click` і `phone_click` як ключові події (Адміністратор → Події → «Позначити як ключову подію»). Тоді в звітах буде видно, скільки людей перейшли до бронювання.

**Звідки приходять люди:** у біо ставте посилання з міткою, напр.
`https://ваш-домен/?utm_source=instagram&utm_medium=bio`, у TikTok — `utm_source=tiktok`, на флаєрах/QR — `utm_source=qr`. GA4 сам розкладе трафік за джерелами.

**Перевірка:** поставте `debug: true`, відкрийте сайт, натисніть F12 → Console. Кожен клік друкується як `[VADE] подія: …`, а пропущені переклади — як попередження. Також є GA4 → DebugView і розширення Chrome *Meta Pixel Helper* / *TikTok Pixel Helper*. Після перевірки поверніть `debug: false`.

## Cookies і згода

Банер з'являється автоматично, щойно вписано хоча б один ID.

- До згоди Google працює в режимі Consent Mode v2 (без cookies), а Meta Pixel, TikTok Pixel і Clarity взагалі не завантажуються.
- Вибір запам'ятовується. Змінити його можна кнопкою «Налаштування cookies» внизу сторінки.
- Для ЄС (зокрема Польщі) потрібна ще сторінка політики конфіденційності: посилання вписати в `site.privacyUrl`.

## UTM-мітки

Якщо сторінку відкрили за посиланням з мітками (`?utm_source=instagram&utm_medium=bio`), ті самі мітки
автоматично додаються до всіх зовнішніх посилань: бронювання SENET, соцмереж, трансляції. Так система
бронювання бачить, звідки прийшов клієнт. Мітки пам'ятаються до кінця сесії; кнопки «Поділитися» та Google Maps
їх не отримують. Вимкнути: `tracking.utmPassthrough: false`.

## Трансляція

У `config.js` → `liveStream`: вписати `url` (Twitch / YouTube / Kick) і поставити `active: true`.
Над кнопкою бронювання з'явиться червона кнопка «Na żywo». Після стріму — повернути `active: false`.

## Вільні ПК (SENET)

Бейдж «🟢 12 wolnych PC» у шапці бере дані з функції `functions/api/status.js`, яка працює лише на Cloudflare Pages.
Ключ SENET зберігається на сервері Cloudflare і в браузер не потрапляє.

1. Cloudflare Pages → проєкт → **Settings → Variables and Secrets** → додати `SENET_API_URL`, `SENET_API_KEY`
   (тип Secret) і, якщо треба, `SENET_CLUB_ID`. Опис усіх змінних — на початку `functions/api/status.js`.
2. Адресу й формат відповіді API уточнити в SENET. Функція розуміє і готові числа, і список ПК зі статусами;
   якщо формат інший — поправити `normalize()` у тому ж файлі.
3. Перевірити вигляд без SENET: змінна `STATUS_MOCK=1` повертає тестові «12 з 20» (потім видалити).

Поки змінні не задані, бейдж просто не показується. Він також ховається, коли клуб зачинено.

## PWA

Сторінку можна додати на головний екран телефона, вона відкривається і без інтернету (остання збережена версія).
Зміни в `config.js` доходять одразу, бо основні файли спершу беруться з мережі.
Якщо додали новий файл до списку `CORE` у `sw.js` — збільште там `VERSION`.

## Публікація: Cloudflare Pages

Функції (`/api/status`) працюють лише при деплої з git або через `wrangler`; перетягування папки в дашборд їх не підтримує.

- **З GitHub:** Cloudflare → Workers & Pages → Create → Pages → підключити репозиторій.
  Build command — порожньо, **Build output directory: `vade`**, Root directory — корінь репозиторію (там лежать `functions/` і `wrangler.toml`).
- **З комп'ютера:** `npx wrangler pages deploy` у корені репозиторію.
- **Локально з функцією:** скопіювати `.dev.vars.example` як `.dev.vars`, вписати ключі, запустити `npx wrangler pages dev`.

`index.html` можна відкрити й подвійним кліком, щоб подивитись, але трекери, карта, PWA і бейдж вільних ПК працюють лише з адреси `https://`.
