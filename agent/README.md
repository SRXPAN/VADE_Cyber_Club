# VADE Agent — вільні/зайняті ПК на сайті + очищення й оновлення ігор

Senet не дає API, тому стан кожного ПК визначає маленька програма на самому ПК і надсилає його на сайт.
Агент замінює `club_night.bat`: усе, що робив нічний скрипт (закрити Steam, стерти логіни, почистити TEMP і кеш, оновити ігри), тепер відбувається **одразу після виходу клієнта з Senet**, а не лише о 01:00.

```
ПК (агент, кожні 5 с)  ──POST /api/report──▶  Cloudflare Pages Functions + D1  ◀──GET /api/status──  сайт (бейдж «9 wolnych PC» + сітка ПК)
```

## Що робить агент

| Коли | Що |
|---|---|
| Постійно | Визначає «вільний / зайнятий» і шле на сайт: одразу при зміні, інакше раз на хвилину. ПК, що мовчить 3 хв, на сайті «вимкнено». |
| Клієнт вийшов (зайнятий → вільний) | Закриває ігри й лаунчери, стирає логіни гравця: Steam, Epic, Riot, Battle.net, EA, Ubisoft, GOG (+ Discord, якщо увімкнути). Чистить TEMP. |
| ПК вільний 10 хв, не частіше ніж раз на 6 год | Оновлює ігри: Steam — через SteamCMD (як раніше), Epic / Riot / Battle.net — запуском лаунчера з клубним входом. |
| Клієнт сів, поки йде оновлення | Оновлення зупиняється за кілька секунд, лаунчер з клубним входом закривається, логін стирається. Steam докачає гру сам при запуску. |
| Раз на добу (після 04:00) | Глибоке чищення кешу Steam — як у старому скрипті. |

## Як визначається «зайнятий»

ПК **зайнятий**, якщо:
1. запущена гра — будь-який процес з папок ігор (бібліотеки Steam і ігри Epic знаходяться самі, решта — `GameFolders`), **або**
2. Senet показує сесію клієнта — ознаки знаходить `learn.bat`, **або**
3. ознак Senet ще немає — хтось рухав мишею чи натискав клавіші останні 10 хвилин.

Пункт 3 — запасний і неточний: клієнт, що відійшов на 10 хвилин без запущеної гри, вважатиметься «вийшов», і його Steam закриється. Тому **один раз запустіть `learn.bat`** — після цього агент орієнтується на сам Senet.

### learn.bat — навчання (5 хвилин, один раз)
Як виглядає сесія Senet зсередини, ніхто заздалегідь не знає, тож агент порівнює три знімки процесів і вікон:
1. запустіть `C:\VadeAgent\learn.bat` (Enter — 90 секунд на кожен крок);
2. **знімок 1** — ПК на екрані входу Senet, клієнта немає;
3. **знімок 2** — увійдіть у Senet тестовим клієнтом, нічого не запускайте;
4. **знімок 3** — вийдіть з клієнта.

Перед кожним знімком — короткі сигнали. Агент покаже, що з'являється лише під час сесії, і запропонує зберегти (`Y`).
Результат — файл `C:\VadeAgent\state\senet-learned.psd1`. Senet на всіх ПК однаковий, тож покладіть цей файл поруч з `install.bat` — інсталятор скопіює його на кожен ПК.
Якщо відмінностей не знайшлося — надішліть `C:\VadeAgent\logs\learn-result.txt`, розберемося.

Що агент бачить зараз і чому — `status.bat`.

## 1. Налаштувати сайт (один раз)

Сайт на Cloudflare Pages, папка `functions/` у корені репозиторію — це API. Потрібні база D1 і секрет.

**Секрет (Token).** Довгий випадковий рядок, однаковий у Cloudflare і на всіх ПК. Згенерувати в PowerShell:
```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 40 | ForEach-Object { [char]$_ })
```

У проєкті є `wrangler.toml`, а він для Cloudflare Pages — головний: прив'язки, додані в панелі, ігноруються. Тому база підключається через файл.

1. Cloudflare → **Storage & Databases → D1 SQL Database → Create** → назва `vade-pcs` → скопіюйте **Database ID**.
2. У `wrangler.toml` розкоментуйте блок `[[d1_databases]]` (приберіть `# `) і вставте ID замість `ВСТАВТЕ_СЮДИ_ID`.
3. Проєкт Pages → Settings → **Variables and Secrets** → Add → тип **Secret**, ім'я `AGENT_TOKEN`, значення — ваш секрет (Production).
4. Commit і push у GitHub — Cloudflare сам зробить новий деплой.

Або з комп'ютера: `npx wrangler d1 create vade-pcs`, вставити ID у `wrangler.toml`, `npx wrangler pages secret put AGENT_TOKEN`, `npx wrangler pages deploy`.
Таблиця в базі створюється сама.

**Перевірка:** відкрийте `https://vade-cyberclub.pages.dev/api/status` — має бути `{"updated":…,"total":0,"pcs":[]}`.
Помилка `D1 database is not bound as DB` — блок у `wrangler.toml` не розкоментовано або не було нового деплою.

## 2. Встановити на ПК

1. В `agent.config.psd1` впишіть **Token** і перевірте **SiteUrl**, `Steam.User`, **Zone**.
   Номер ПК на сайті береться з імені комп'ютера (`VADE-PC07` → `PC 7`). Інші зони — у `ZoneByPc`, напр. `'*PC2[1-5]' = 'Bootcamp 5×5'`.
2. Скопіюйте папку `agent` на ПК (флешка, мережа) і запустіть **install.bat**. Він:
   - скопіює все в `C:\VadeAgent` і закриє папку від запису звичайним користувачам (скрипт працює від SYSTEM — гравець не повинен мати змоги його змінити);
   - завантажить SteamCMD і попросить увійти клубним акаунтом Steam (пароль + Steam Guard) — як старий скрипт;
   - **видалить старе завдання «Club Night»** від `club_night.bat`;
   - створить три завдання Windows у папці `\VADE\`: `Agent` (SYSTEM, з увімкненням ПК), `Probe` (помічник у сесії користувача), `Update` (оновлення від вашого облікового запису — попросить пароль Windows, як раніше);
   - надішле тестовий звіт на сайт і покаже стан.
3. На першому ПК запустіть **learn.bat**, покладіть `senet-learned.psd1` поруч з `install.bat` і ставте на решту ПК.

Оновити агента або змінити налаштування на всіх ПК — та сама папка і `install.bat` ще раз. Зміни в `C:\VadeAgent\agent.config.psd1` агент підхоплює сам за кілька секунд.

## 3. Оновлення ігор з інших лаунчерів

| Лаунчер | Вихід гравця | Оновлення ігор |
|---|---|---|
| Steam | ✔ | ✔ SteamCMD, клубний акаунт, без запуску Steam (як раніше) |
| Epic | ✔ | warmup — потрібен `save-club-login.bat Epic` |
| Riot (Valorant, LoL) | ✔ | warmup — потрібен `save-club-login.bat Riot` |
| Battle.net | ✔ | warmup — потрібен `save-club-login.bat Battle.net` |
| EA, Ubisoft, GOG | ✔ (закриття + стирання кешу входу) | ✖ — оновлюються при запуску гри або модулем Game Update у Senet |

**warmup:** коли ПК вільний, агент кладе в профіль збережений **клубний** вхід, запускає лаунчер згорнутим, чекає, поки той докачає оновлення (запис на диск менше 1 МБ/с протягом 3 хвилин, максимум 90 хв), закриває лаунчер і стирає вхід. Якщо клієнт сідає раніше — усе зупиняється за секунди.

Зберегти клубний вхід (один раз на лаунчер):
1. на ПК, де за Windows — звичайний клубний користувач, відкрийте лаунчер, увійдіть **клубним** акаунтом, поставте «запам'ятати мене» і ввімкніть автооновлення ігор у налаштуваннях лаунчера;
2. запустіть `save-club-login.bat` і введіть назву (`Epic`, `Riot` або `Battle.net`).

Вхід зберігається в `C:\VadeAgent\club-logins` (доступ лише SYSTEM і адміністраторам), а з профілю користувача одразу стирається. Щоб не повторювати на кожному ПК — покладіть папку `club-logins` поруч з `install.bat`.
Лаунчер, для якого вхід не збережено, просто пропускається.

## 4. Обов'язково перевірити на одному ПК

Агент написано без доступу до ваших ПК, тому перед установкою на весь зал:

- [ ] **Senet не вбиває помічника.** Senet може закривати «сторонні» програми під час сесії. Після `install.bat` увійдіть клієнтом і через хвилину подивіться `status.bat`: рядок «Помічник: працює». Якщо «не працює» — додайте `powershell.exe` і `wscript.exe` у дозволені програми Senet. Без помічника агент усе одно працює (за процесами гри й Senet), але не бачить вікон і часу без миші.
- [ ] **Логіни справді стираються.** Увійдіть у Steam, Epic, Riot, Battle.net, EA, Ubisoft своїм тестовим акаунтом → `cleanup-now.bat` → відкрийте кожен лаунчер: він має просити вхід. Для Steam — ті самі кроки, що у вашому робочому `club_night.bat`, плюс стирання збережених токенів входу з `config.vdf`. Для інших — відомі розташування файлів входу, але лаунчери їх іноді змінюють. Якщо якийсь лаунчер лишився залогіненим — напишіть, який, і поправимо `Launchers` у налаштуваннях.
- [ ] **Оновлення.** `update-now.bat` — оновлення в цьому вікні; журнал `C:\VadeAgent\logs\update.log`. Якщо там «ПОМИЛКА ВХОДУ SteamCMD» — `steam-login.bat`.
- [ ] **Сайт.** ПК з'явився на сайті, змінює стан протягом 5–30 с після входу/виходу клієнта.

## Файли

| Файл | Що це |
|---|---|
| `agent.config.psd1` | **усі налаштування** (коментарі всередині) |
| `vade-agent.ps1` | сам агент |
| `install.bat` / `uninstall.bat` | встановити / прибрати завдання |
| `learn.bat` | навчити розпізнавати сесію Senet |
| `status.bat` | що агент бачить зараз |
| `save-club-login.bat` | зберегти клубний вхід лаунчера для оновлень |
| `steam-login.bat` | повторний вхід у SteamCMD |
| `cleanup-now.bat`, `update-now.bat` | очищення / оновлення вручну (для перевірки) |
| `C:\VadeAgent\logs\` | `agent.log` (зміни стану, очищення), `update.log`, `learn-result.txt` |
| `C:\VadeAgent\pause` | створіть порожній файл з такою назвою — агент перестане чистити й оновлювати (на час обслуговування ПК); стан на сайт іде далі |

## Адміністратору

- Стан з поясненнями для всіх ПК (чому зайнятий, яка гра, чи йде оновлення):
  ```powershell
  Invoke-RestMethod https://vade-cyberclub.pages.dev/api/status -Headers @{ Authorization = 'Bearer ВАШ_TOKEN' } | Select-Object -Expand pcs | Format-Table name, state, detail
  ```
- Прибрати ПК із сайту (списали, перейменували): `Invoke-RestMethod 'https://vade-cyberclub.pages.dev/api/report?id=VADE-PC07' -Method Delete -Headers @{ Authorization = 'Bearer ВАШ_TOKEN' }`
- Ліміти безкоштовного Cloudflare D1 — 100 000 записів на добу. Агент пише раз на хвилину + при змінах: 30 ПК ≈ 45 000 на добу.
- Відвідувачі сайту бачать лише номер ПК, зону і вільний/зайнятий. Що саме запущено — лише з Token.
